# Release notes

## 0.6.0 — 2026-11-24

First repository-organized GitHub release, based on the tested 0.5.2 implementation.

- Preserves runtime JavaScript, internal package/service identifiers and schema 6.
- Adds MIT licensing, install/recovery guidance, explicit trust/privacy boundaries and verification limits.
- Adds portable synthetic test tooling and a checked, allowlisted installation archive.
- Excludes private development history, user trajectories, live state, cost exports and machine-specific build paths.

This is release engineering, not a new execution permission or a widened automation policy. No new work is authorized by upgrading. DSH 0.2.2-rc.5 remains the only declared compatible release.

### Features inherited from 0.5.2

Reviewed dispatch with fresh explicit user confirmation and atomic hand-back; independent native Sessions; direct peer exchanges and unanimously agreed proposals; exact unfinished-task continuation; bounded waiting reassessment from decisions, handoffs and required replies; protected manager holds; With user; retirement/reopening/startup review; active-team-only trailing status indicators.

### Important compatibility note

Keep `@local/session-coordination`, the `session-coordination` patch entry, `sessionTeams` service and existing storage-domain names unchanged. They are technical upgrade identities, not a publication branding error. Internal CSS/locale/context identifiers may retain historical version labels. Legacy schema modules are required migration code, not disposable old builds.
